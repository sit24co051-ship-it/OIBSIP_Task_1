# Unit Converter Application

## Introduction
The Unit Converter Application is an Android-based utility app developed to perform quick and accurate conversions between different measurement units. The application is designed with a simple and user-friendly interface, making everyday calculations easy and efficient.

## Features
- Length Conversion
- Weight Conversion
- Temperature Conversion
- Instant Results
- Clean and Responsive User Interface

## Technologies Used
- Java
- XML
- Android Studio

## Project Objective
The main objective of this project is to provide a convenient tool for converting values across multiple measurement systems while enhancing user experience through a simple mobile interface.

## Learning Outcomes
- Android Activity Management
- User Interface Design using XML
- Event Handling in Java
- Input Validation and Data Processing
